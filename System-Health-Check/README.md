# System Health Check Script

## Overview

A Bash script that collects important Linux system information and displays a health report.

## Features

- Displays hostname
- Shows current user
- Shows date and time
- Displays system uptime
- Shows disk usage
- Displays memory usage
- Lists running processes

## Technologies Used

- Linux
- Bash scripting

## How to Run

Make the script executable:

```bash
chmod +x health_check.sh
./health_check.sh
